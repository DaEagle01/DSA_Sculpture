# Problem-solving patterns

One-line trigger for each pattern. Recognize the signal, reach for the pattern.

| Pattern | Reach for it when... |
|---|---|
| Two pointers | sorted array/list, looking for a pair/triplet, or comparing from both ends |
| Sliding window | contiguous subarray/substring with a size or condition constraint |
| Fast & slow pointers | linked list cycle detection, finding the middle |
| Binary search | sorted data, or "find the boundary where a condition flips" (search on answer) |
| BFS | shortest path / fewest steps in an unweighted graph or grid |
| DFS / backtracking | explore all paths, combinations, permutations, or "is there a path" |
| Prefix sum | repeated range-sum queries over a static array |
| Monotonic stack | "next greater/smaller element" type questions |
| Union-Find | grouping/connectivity queries, cycle detection in an undirected graph |
| Heap / top-K | "k largest/smallest", running median, merge k sorted lists |
| Dynamic programming | overlapping subproblems + optimal substructure; "count ways" or "min/max cost" |
| Greedy | local optimal choice provably leads to global optimal (interval scheduling, etc.) |
